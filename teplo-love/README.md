# ТЕПЛО — сайт з генерацією макетів OpenAI

Клієнт обирає до 10 дизайнів, додає 1 спільне або 2 окремі фото.
Сайт зменшує фото на пристрої й послідовно створює персональне зображення
для кожного дизайну через серверний `/api/generate` та OpenAI Images Edits.
Мультяшні дизайни перетворюють людей на персонажів. Для кожного готового
макета доступні передня/задня сторони, календар з обраною датою та анімація
проявлення на чашці з блискітками. Анімація не є реальною зйомкою.

## Публікація у Vercel

1. Завантажте ВСІ файли цієї папки у репозиторій. Не завантажуйте сам ZIP.
2. Якщо папка лежить у `teplo-love/` всередині іншого репозиторію, створіть
   ОКРЕМИЙ Vercel project із Root Directory `teplo-love`. Налаштування
   основного сайту BabyGirl змінювати не потрібно.
3. Application Preset: Other. Build Command та Install Command: порожні.
   Output Directory: `.` (корінь проєкту).
4. Environment Variables → `OPENAI_API_KEY`: ваш секретний ключ OpenAI.
   Без префіксів `NEXT_PUBLIC_` або `VITE_`. Ніколи не записуйте ключ у GitHub.
5. Для закритого тестування рекомендовано встановити `GENERATION_ACCESS_CODE`
   та ввести цей код у розділі завантаження фото. Перед відкритим запуском
   налаштуйте постійні обмеження частоти запитів у Vercel Firewall.
6. Натисніть Deploy. Після зміни ключа — Redeploy.
7. Відкрийте адресу саме цього Vercel project, оберіть ОДИН дизайн, додайте
   фото й створіть макет. Перевірте витрату запиту в OpenAI Usage.

Доступ до GPT Image та достатній баланс мають бути у проєкті OpenAI,
якому належить ключ. Може знадобитися верифікація організації.
Один дизайн = один платний запит, десять дизайнів = десять запитів.
Автоматичних повторів платних запитів немає. Зупинка завершує поточний
запит і не запускає наступний. Повторне натискання створює макети заново.

## Що потрібно знати

- Попередній статичний сайт `chatgpt.site` не отримає сервер Vercel автоматично.
- Саме збереження ключа без публікації цього коду не вмикає генерацію.
- Фото передаються OpenAI, але цей код не записує їх у базу чи журнали.
  Згенеровані результати залишаються на сторінці до її перезавантаження.
- ШІ орієнтується на вибраний дизайн, але не гарантує точне відтворення
  друкарського шаблону чи ідентичність облич. Фінальний макет погоджується
  перед друком; імена й календар додаються звичайним кодом.
- Надсилання замовлення та збереження в Supabase тут не підключені.
  Наявна форма завантажує чернетку замовлення.
- Перевірки: `npm test`. Реальний запит потребує вашого ключа на сервері.
